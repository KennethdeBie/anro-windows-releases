# Anro Metadata Importer — Windows-releases

Dit is het openbare distributiekanaal voor Anro Metadata Importer op Windows x64.
Hier staan uitsluitend installers en updatebestanden. De ontwikkelrepository blijft privé.

## Installeren en bijwerken

Installeer de bootstrapversie met het GitHub-updatekanaal één keer. De app controleert daarna zelf op hogere stabiele versies. Updates worden gedownload vanuit deze repository en pas na een veilige afsluiting geïnstalleerd.

Bij iedere release horen de Windows-installer, de bijbehorende blockmap en latest.yml. Download installers uitsluitend uit de Releases-sectie van deze repository.

De huidige builds zijn niet code-ondertekend; Windows kan bij installatie een SmartScreen-melding tonen.

## Lokale gegevens

Accounts, databases, opdrachten, historie en versleutelde CCV-configuratie blijven op de eigen Windows-pc. Deze repository bevat geen credentials, klantgegevens of lokale databases. Deel API-keys nooit via GitHub.

De releasebestanden en ingebouwde applicatiecode zijn openbaar downloadbaar. De broncoderepository wordt niet openbaar gemaakt.
